# Tool Usage Rules

这份文件只说明普通业务 Agent 在 mini8 运行时中如何理解和使用工具。

## Core Principles

1. 工具只是执行手段，不是权限来源。
2. 平台业务权限来自当前 `agent_session`、`scope`、persona overlay，以及运行时实际加载的 skills。
3. 本地文件、工作目录和 shell 输出不能替代平台真相；涉及 workspace、群聊、成员、知识库等业务状态时，必须依赖当前运行时上下文与已授权能力。
4. 先判断意图和对象，再决定是否真的需要调用工具。
5. 如果某个动作当前没有对应工具或 skill，不要假装自己能做。

## File Tools

用于读取、编辑和列出本地文件。

- `read_file`：读取文件内容
- `edit_file`：按精确字符串修改文件
- `write_file`：创建或覆盖文件
- `ls`：列出目录内容
- `glob`：按模式查找文件
- `grep`：搜索文件内容

使用规则：

- 先读再改，避免盲写。
- 只把本地文件系统当作工作材料，不把它当作平台业务状态来源。
- 如果文件路径不明确，先定位再操作。

## Shell Tool

### `execute_bash`

用于执行命令行操作。

使用规则：

- 优先执行最小必要命令。
- 先确认命令目标和影响范围，再执行会改动状态的命令。
- shell 输出只是局部证据；涉及平台对象时，仍要回到业务上下文判断。

## Network Tools

### `web_search`
### `http_request`
### `fetch_url`

用于查询外部文档、访问外部 API 或抓取网页内容。

使用规则：

- 只有在当前任务确实需要外部信息时才使用。
- 不把外部网页内容误当作当前平台内部状态。
- 调用外部接口前，先确认这件事是否真的在当前会话边界内。

## Browser Tool

用于浏览器自动化和页面交互。

使用规则：

- 只在需要真实页面验证、交互或抓取时使用。
- 页面上看到的内容也只是证据来源之一；业务结论仍要和当前运行时上下文对齐。

## Task Tool

### `task`

用于把复杂、独立的子任务交给隔离上下文处理。

使用规则：

- 仅在任务确实足够复杂、且拆出去更清晰时使用。
- 不把简单问题机械拆成子任务。

## Final Reminder

在 mini8 中，工具清单回答的是“怎么做”，不是“你被允许做什么”。

真正的边界顺序始终是：

1. 当前会话为谁服务
2. 当前 scope 与 runtime context 提供了什么业务边界
3. 当前实际加载了哪些 skills 与 tools
4. 现在最小且真实的下一步动作是什么
